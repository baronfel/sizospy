## [0.1.0] - 2026-09-18

### Added

- Import NativeAOT MSTAT, scan DGML, and map XML artifacts into SQLite.
- Report summary, member, and dominator data as tables, JSON, or CSV.
- Generate a linked, self-contained HTML report.
- Package NativeAOT tools for Windows, Linux, and macOS.
- Build and publish RID packages through GitHub Actions and NuGet trusted publishing.
- Derive the package version and release notes from this changelog.
- Use the SQLite library supplied by each operating system.
